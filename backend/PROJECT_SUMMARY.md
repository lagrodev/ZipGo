# Информационная система каршеринга

Разработал веб-приложение (REST API) для управления каршеринговым сервисом с полным циклом аренды автомобилей.

•	Реализована система аутентификации и авторизации на базе JWT (Spring Security). Добавлена ролевая модель доступа, верификация пользователей по email, функционал "Избранное" для автомобилей.

•	Спроектирована архитектура системы с использованием многослойного подхода (REST контроллеры, сервисы, репозитории). Создан полный набор UML-диаграмм (use case, sequence, component, deployment, statechart).

•	Реализована интеграция с внешними сервисами: почтовый сервер (Spring Mail), объектное хранилище MinIO для файлов. Настроена контейнеризация приложения и зависимостей (Docker Compose).

•	Технологии: Java 21, Spring Boot, Spring Security, Spring Data JPA, PostgreSQL, Flyway, JWT, MapStruct, Docker, MinIO, Swagger/OpenAPI, Testcontainers.
