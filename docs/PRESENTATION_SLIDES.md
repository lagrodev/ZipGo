## Технические детали для подготовки

### Рендер PlantUML диаграмм

**Способ 1: Онлайн**
1. Открыть https://www.plantuml.com/plantuml/uml/
2. Скопировать содержимое `.puml` файла
3. Вставить в редактор
4. Экспортировать как PNG/SVG

**Способ 2: VS Code**
1. Установить расширение "PlantUML"
2. Открыть `.puml` файл
3. `Alt+D` для preview
4. Экспортировать (правый клик → Export Current Diagram)

**Способ 3: CLI**
```bash
# Установить PlantUML
brew install plantuml  # macOS
# или скачать plantuml.jar

# Рендер всех диаграмм
plantuml diagrams/*.puml
# Создаст PNG файлы рядом
```

### Скриншоты приложения

**Что снять:**
1. Экран входа (LoginFragment)
2. Каталог с автомобилями (CatalogueFragment)
3. Bottom sheet фильтров (FiltersBottomSheet) с выбранными чипами
4. Детальная карточка авто (CarDetailFragment)
5. Список контрактов (ContractsFragment)
6. Профиль со статистикой (ProfileFragment)

**Как снимать:**

## Рекомендации по дизайну слайдов

### Цветовая схема (из приложения)
- **Primary**: `#1E88E5` (синий)
- **Primary Dark**: `#1565C0`
- **Accent**: `#FF6B35` (оранжевый)
- **Background**: `#FAFAFA`
- **Text**: `#212121`

### Шрифты
- **Заголовки**: Roboto Bold / Inter Bold
- **Текст**: Roboto Regular / Inter Regular
- **Код**: JetBrains Mono / Fira Code

### Лайоут
- Широкие поля (минимум 10% с каждой стороны)
- Крупные заголовки (36–48pt)
- Основной текст (18–24pt)
- Код (14–16pt, моноширинный)

### Визуал
- Скриншоты с тенями/рамками для глубины
- Диаграммы в высоком разрешении (PNG/SVG)
- Consistent alignment (всё выровнено по сетке)
- Анимации переходов: fade/slide (не злоупотреблять)
